This directory is the configuration root of a CakePHP application and is organized into distinct responsibilities. `paths.php` defines global path constants (ROOT, APP, CONFIG, WWW_ROOT, TMP, LOGS, CACHE, RESOURCES) loaded first by `bootstrap.php`. The main bootstrap (`bootstrap.php`) registers the PhpConfig engine, loads `app.php` then overlays `app_local.php` via `Configure::load`, applies debug-time cache durations, sets timezone/locale/inflection rules, registers ErrorTrap/ExceptionTrap (branching to `bootstrap_cli.php` when `PHP_SAPI === 'cli'`), configures Cache/ConnectionManager/TransportFactory/Mailer/Log/Security from consumed config keys, registers mobile/tablet request detectors, and writes CakePdf settings. `routes.php` declares URL-to-controller mappings using `DashedRoute` with CSRF middleware scoped under `/`. Environment-driven configuration is layered: `app.php` provides defaults read via `env('KEY', default)`, while `app_local.php` (git-ignored) overrides secrets per environment; an optional `.env` loader via josegonzalez/php-dotenv is present but commented out. CLI-specific behavior is isolated in `bootstrap_cli.php` (separate log filenames). Database schema lives under `schema/` (`i18n.sql`, `sessions.sql`) and `Migrations/schema.sql`, with `Seeds/` reserved for data seeding. Dependency direction is one-way: bootstrap reads config files and writes into CakePHP's runtime services without depending on application business logic.

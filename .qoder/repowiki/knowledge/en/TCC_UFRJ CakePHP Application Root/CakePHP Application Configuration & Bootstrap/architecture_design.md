This module is the configuration root of a CakePHP application. `paths.php` defines global path constants (ROOT, APP, CONFIG, WWW_ROOT, TMP, LOGS, CACHE, RESOURCES) used throughout the framework. `bootstrap.php` is the main entry that loads these paths, requires the core bootstrap, registers the `PhpConfig` engine, loads `app.php` then overlays `app_local.php` (if present), applies debug-time cache durations, sets timezone/locale/inflection rules, registers error/exception traps (branching to `bootstrap_cli.php` in CLI mode), configures Cache/ConnectionManager/TransportFactory/Mailer/Log/Security from the loaded config, and adds mobile/tablet request detectors plus CakePdf settings. `routes.php` declares URL-to-controller mappings using `DashedRoute` with CSRF middleware scoped under `/`. `requirements.php` enforces PHP ≥ 8.1, intl, ICU ≥ 50.1, and mbstring extensions at runtime. Environment-driven configuration is supported via `env()` calls in `app.php`/`app_local.php` and an optional `.env` loader (commented out). Database schema and migrations live under `schema/` (`i18n.sql`, `sessions.sql`) and `Migrations/schema.sql`; `Seeds/` is reserved for data seeding. The dependency direction is one-way: bootstrap reads config files and writes into CakePHP's runtime services; no code in this directory depends on application business logic.

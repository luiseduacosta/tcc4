Templates follow CakePHP's conventional directory layout: each controller has a matching subdirectory under `templates/` (e.g., `Estudantes/`, `Monografias/`, `Users/`, `Docentes/`, `Professores/`, `Tccestudantes/`, `Agendamentotccs/`, `Areamonografias/`) containing standard CRUD action files (`add.php`, `edit.php`, `index.php`, `view.php`). Shared UI is factored into `element/` (reusable fragments like `menu_monografias.php`, `paginator.php`, `templates.php`, and `flash/` variants) and `layout/` (`default.php` as the main HTML shell with Bootstrap 5.3 + CKEditor 5 + jQuery, plus `ajax.php` and `error.php` for special response types). Email rendering uses the `email/html/` and `email/text/` pairs with corresponding `layout/email/` wrappers. The `Pages/` folder holds static pages such as `home.php`. Error responses are rendered from `Error/error400.php` and `Error/error500.php`. Dependency direction is one-way: action templates consume elements and layouts via `$this->element()` and `$this->fetch()`, never the reverse; data flows in through CakePHP's `AppView` variables (entities, request attributes like `identity`, and paginator helpers).

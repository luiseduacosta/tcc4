Standard CakePHP skeleton: repository-root `index.php` delegates to `webroot/index.php`, which boots the framework and dispatches HTTP requests into the `src/` MVC layer (controllers, ORM tables/entities, policies). `config/` supplies bootstrap, routing, environment overrides, and database migrations consumed by both runtime code and the test suite. `templates/` provides the view layer rendered by controllers, while `tests/` mirrors `src/` under `App\Test\` for PHPUnit integration/unit tests driven by `phpunit.xml.dist`. `bin/` exposes the CakePHP console plus one-off Python refactoring helpers used during development. Composer (`composer.json`) autoloader maps `App\` to `src/` and `App\Test\` to `tests/`, registers authentication, authorization, migrations, and PDF-generation plugins, and centralizes dev tooling via script aliases.

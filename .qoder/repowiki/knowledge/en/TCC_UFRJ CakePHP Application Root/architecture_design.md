The project is a standard CakePHP 5 skeleton: `index.php` at the repository root delegates to `webroot/index.php`, which boots the framework and dispatches HTTP requests into the `src/` MVC layer (controllers, ORM tables/entities, policies). `config/` holds bootstrap, routing, and environment overrides consumed by both runtime code and the test suite. `templates/` provides the view layer rendered by controllers, while `tests/` mirrors the `src/` structure under `App\Test\` for PHPUnit integration/unit tests driven by `phpunit.xml.dist`. `bin/` exposes the CakePHP console plus one-off Python refactoring helpers used during development. Composer (`composer.json`) autoloads `App\` from `src/` and `App\Test\` from `tests/`, registers `cakephp/authentication`, `authorization`, `migrations`, and PDF generation plugins, and centralizes dev tooling (PHPStan level 5 with CakePHP extensions, CodeSniffer, DebugKit) via scripts like `composer check`, `composer stan`, and `composer test`.

Built on CakePHP 4 with the standard `src/` layout. `Application.php` extends `BaseApplication` and implements both `AuthenticationServiceProviderInterface` and `AuthorizationServiceProviderInterface`, wiring the middleware pipeline (Error → Asset → Routing → Authentication → Authorization) and configuring session/form authenticators plus an `OrmResolver`-based authorization service. `Controller/AppController.php` is the base controller that loads Flash, Authentication, and Authorization components and whitelists public actions (`index`, `view`, `busca`, `download`). Domain features are organized per resource: each entity in `Model/Entity/` has a matching Table in `Model/Table/` defining associations, validation rules, and integrity rules; each Table has a sibling policy in `Policy/` implementing fine-grained access checks (e.g. role-based via `categoria`). Console tooling lives under `Console/Installer.php` (Composer post-install hook creating writable dirs, copying `app_local.php`, generating `security.salt`) and `Command/ConsoleCommand.php`. Views extend `View/AppView.php` with placeholder helper loading points. Dependency direction is one-way: Controllers → Tables → Entities → Policies; the Application bootstrap depends on no domain code.

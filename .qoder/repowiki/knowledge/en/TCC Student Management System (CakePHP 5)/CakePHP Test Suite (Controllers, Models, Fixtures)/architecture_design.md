Organized as a standard CakePHP test suite under `tests/` with three top-level sections: `Fixture/` holds one `*Fixture.php` per table defining seed records via `TestFixture`; `TestCase/` mirrors the application's namespace layout with `Controller/`, `Model/Table/`, and `View/Helper/` subdirectories containing corresponding `*Test.php` classes extending `Cake\TestSuite\TestCase`; `bootstrap.php` bootstraps the test runner by loading the app autoloader and config, configuring an in-memory SQLite connection for DebugKit, and fixing the session ID for CLI. Controller tests use `IntegrationTestTrait` to simulate HTTP requests, while Table tests obtain entities through `getTableLocator()`. A single `ApplicationTest` verifies plugin registration and middleware pipeline.

Two distinct sub-trees with no shared code:
- `bin/` contains the CakePHP application's CLI bootstrap. `cake.php` is the single PHP entry point that loads `config/requirements.php`, registers Composer's autoloader, instantiates `App\Application`, and delegates execution to `Cake\Console\CommandRunner`. The POSIX `cake` shell script and Windows `cake.bat` wrapper both resolve their own real path (handling symlinks) and exec the PHP interpreter against `cake.php`, forwarding `$argv`/`%*` unchanged.
- `scratch/` holds standalone, one-shot Python scripts (`fix_annotations.py`, `fix_double_docblocks.py`, `fix_query_annotations.py`, `rename_questiones.py`) that walk directories under `/home/luis/Html/tcc5/src`, `templates`, and `tests`, read each `.php` file into memory, apply regex or string replacements, and write back only when content changed. These scripts have no package structure, no dependencies beyond the standard library, and are not invoked by the application at runtime.

Copy `config/.env.example` to `config/.env` and uncomment the dotenv loading block in `bootstrap.php` to enable environment-variable driven configuration. Copy `app_local.example.php` to `app_local.php` to override secrets and DB credentials per environment. Run database migrations against `Migrations/schema.sql` and seed tables defined under `schema/` (`i18n.sql`, `sessions.sql`) before first use.
